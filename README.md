# ASA Enrolment Agency (AI + Chinese)

An autonomous AI agency of **8 employees (1 Project Manager + 7 specialists)** that runs enrolment for the
after-school activities (ASA) at International School Premjers, Riga: the **AI Club** for kids and **Chinese
language classes**. Built for the RNU course *Programming for Data Science* (lecturer Amit Joshi), assignment
"Design, Deploy & Manage an Autonomous AI Agency". Employee kits follow the
[markfulton/ai-employees](https://github.com/markfulton/ai-employees) conventions (`employee.json`, `ROLE.md`,
`work-profile.json`, `.installed.json` receipts).

> **Data notice:** all children, parents, emails and phones in `data/sample/` are **synthetic sample data**
> generated by `scripts/generate_sample_data.py` (reserved `example.com` domain). No real personal data.

## What it does

| # | Employee | Does |
|---|---|---|
| 1 | Project Manager | Plans the day, dispatches and audits tasks, keeps the ledger, drafts the daily brief, answers the Boss in chat |
| 2 | Intake Officer | Parses the form (program AI / Chinese / both, age, Chinese level, availability), imports registers |
| 3 | Scheduler | Groups by program + age band (AI) or level band (Chinese), balances groups, no same-day clash for kids in both |
| 4 | Communications Officer | Confirmation, waitlist and reminder emails per program; sending is Blocked until the Boss approves |
| 5 | Parent Support | FAQ triage for both programs, escalates fees, medical and unknown questions |
| 6 | Content Writer | Lesson posts for both programs on 4 channels, poster copy, posts on request |
| 7 | Analyst | KPIs split by program, dashboard data, Sheets exports |
| 8 | QA Auditor | Duplicates, consent, email format, age, availability, missing Chinese level |

Every task is logged with: Task ID | Timestamp | Assigned By | Agent Name | Task Description | Priority |
Status (Queued / In Progress / Blocked / Completed) | Output / Result Link | Completion Time.

## Quick start

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
python scripts/generate_sample_data.py          # synthetic sample form + parent inbox
python scripts/hire_employees.py                # writes employees/*/employee.json + .installed.json
python scripts/run_pipeline.py --reset          # one agency day, 13 tasks end to end
python scripts/pm_chat.py "Which tasks are blocked, and why?"
python scripts/assign_task.py "Content Writer" "Write 3 LinkedIn posts about our new service" --due 2026-11-26
streamlit run dashboard/app.py                  # Boss Command Center (login: see .env.example)
python -m unittest discover tests
```

## Public landing page with application form

`asgi.py` serves one web service: the Boss dashboard at `/` and the parents' landing page at `/apply`
(`web/landing.html`). A submitted form is saved to `state/web_applications.csv` (source "Web form") and the
Project Manager immediately dispatches Intake, QA, Scheduler, Communications (draft email only) and Analyst tasks.
The dashboard tab "Web applications" lists real submissions separately from the synthetic sample.

```bash
uvicorn asgi:app --host 0.0.0.0 --port 8501      # dashboard at /, form at /apply
# or, as on Render:
ASA_SERVE_ASGI=yes python scripts/run_pipeline.py --reset
```

Render start command (recommended): `python scripts/run_pipeline.py --reset && uvicorn asgi:app --host 0.0.0.0 --port $PORT`.
Note: on the free plan the SQLite file and submissions are lost on restart or redeploy.

## Layout

```

employees/<slug>/                employee.json, ROLE.md, work-profile.json, .installed.json
asa/agents/                      one module per employee, project_manager.py dispatches
asa/bridges/sheets_bridge.py     Google Sheets bridge (CSV export + gspread push)
asa/bridges/email_bridge.py      Email bridge (.eml/.html drafts, SMTP only after approval)
asa/chat.py                      PM / employee chat, answers from the database, can create tasks
dashboard/app.py                 Streamlit Boss Command Center: A assign, B task board, C reports, D chat, E employees
scripts/                         pipeline, chat, task assignment, sample data, approved sending
outbox/                          email drafts (confirmations, waitlist, reminders, daily_brief)
reports/                         intake, QA, support, KPI reports, daily brief HTML
exports/                         Sheets CSVs, post drafts
docs/                            proposal, agency plan (+PDF), workflow diagram, demo script, checklist
```

## Google Sheet

Tabs: Dashboard (formulas + 5 charts), Ledger, Applications, Schedule, Attendance, About.
Live push: create a Google Cloud service account, share the sheet with it as Editor, set `ASA_SHEET_ID` and
`GOOGLE_APPLICATION_CREDENTIALS`, `pip install gspread google-auth`. `run_pipeline.py` then pushes every run.

## Email

All emails are drafts in `outbox/` (status "Draft (not sent)"). To send, after the Boss approves:
`ASA_ALLOW_SEND=yes python scripts/send_approved.py --kind daily_brief --send` with SMTP settings in `.env`
(Gmail: App Password). For the daily brief schedule a cron job, for example `0 18 * * 1-5`.

## Guardrails

Nothing is emailed or posted without the Boss's approval. Agents never invent facts: unknown questions are
escalated. Secrets live in `.env`, which is git-ignored.
